# busca-bairros-c
Projeto em C para leitura de arquivos CSV e busca de bairros por cidade

Projeto desenvolvido para praticar:

- Structs
- Leitura de arquivos CSV
- Manipulação de Strings
- Busca de dados em C

## Como executar

Compilar:

gcc ex01.c -o programa

Executar:

./programa

## Exemplo

Digite a cidade:
LA PAZ
